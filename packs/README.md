# Evaluation pack library

| Pack | Job | Contents | State |
|---|---|---|---|
| [Alder v0.1](alder/v0.1/README.md) | Evidence-grounded project updates | 12 cases, 133 criteria, 5 categories, 9 themes | MIT licensed; fictional, operator-assisted; proposed corrections retained |

Versions are immutable. Use a new path for changed sources or criteria.
The [MIT license](../LICENSE) covers these original fictional examples.
Historical private-development fields remain in the original inputs and
provenance; current licensing is defined by the root LICENSE.
Case count is descriptive, not a quality score or a claim of universal
coverage. The generation workflow can be used for new tasks; this catalogue
does not claim that planned categories already have validated packs.

For a smaller task-to-output explanation, see the separately labelled
[meeting-actions example](../examples/meeting-actions/README.md): six cases,
17 proposed criteria, three categories and an explicit conditional-commitment
gap. It uses the same pack format, renderer and exports.
The [ticket-triage walkthrough](../docs/walkthrough.md) provides another task.
Both are authored tutorials with no unattended-generation or target-performance claim.
