# Release notes

## 0.1.0.dev7

Approved for publication on November3 after the voice revision. The preceding
public version is dev6, including the October29revision at commit06718aa.

- Read the complete six-case meeting example directly on GitHub. Interactive
  HTML links explicitly describe downloading and opening locally.
- Start Here contains a filled-in task example, both assistant messages and
  three concrete design-approval questions.
- AGENTS provides one operational entry contract. The workflow distinguishes
  assisted and deliberately separated contexts at each affected stage.
- Typed-intake startup keeps the original bytes in `imported-intake.json`,
  including identity, input shape and provenance. Edits require a new current
  intake before freezing.
- Validation uses the declared document type to choose relevant error
  diagnostics without weakening acceptance. A preparation hint appears only
  when the existing preparation operation can complete omitted derived fields.
- Command help explains accepted documents, outputs and limits. Generated
  HTML/JSONL uses LF consistently across platforms.
- Casebook overviews lead directly to a populated scenario. Five attributed
  demonstration frames explain changed commitments and valid paraphrases.
- Collection-first case checklists include shared format rules in place,
  with their evidence, applicability and acceptable alternatives. They no
  longer point readers to an Overview that omits those checks.

Existing example source inputs, criteria and review states are unchanged.
Updated HTML and screenshots are projections of those same definitions.
Offline checks establish mechanics and consistency; human usability,
conversion and independent evaluation quality remain unmeasured.
Target execution and grading remain outside this package.
