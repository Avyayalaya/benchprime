The PNG versions work in ordinary Markdown/image viewers. Text explanations
and the GitHub-native collection overview remain available independently of
the images. No third-party stock imagery, customer logos or performance
claims are embedded. No reuse license has been selected for these assets.

The README uses `picture` sources for narrow screens, with a regular PNG
fallback. Each SVG retains selectable text, a title and a description.
Responsibility labels are shortened for reading; their canonical IDs and
meanings remain in the design catalogue. These maps explain the method and
its limits; they do not claim that every responsibility is enforced by code.
