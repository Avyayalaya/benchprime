The PNG versions work in ordinary Markdown/image viewers. Text explanations
and the GitHub-native collection overview remain available independently of
the images. No third-party stock imagery, customer logos or performance
claims are embedded. These original assets are covered by the repository's
[MIT license](../LICENSE).

The README keeps the three maps in an expandable section; the methodology
page shows them beside the corresponding design choices. Both use `picture`
sources for narrow screens, with a regular PNG fallback. Each SVG retains
selectable text, a title and a description.
The figures prioritize product reasoning. The eleven responsibilities, canonical
IDs and detailed execution/context rules remain in the design catalogue and
workflow. These illustrations explain the method and its limits; they do not
claim that every responsibility is enforced by code or that the controls have
independent human calibration.
